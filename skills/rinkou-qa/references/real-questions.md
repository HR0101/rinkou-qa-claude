# 実際に来た質問の系統

輪講で実際に出た質問を集めて，どんな型が来るかを分けたものである．想定質問を作るとき，資料の文ごとの観点（[checklist.md](checklist.md)）に加えて，この型を当てる．人名と回答者名は載せない．

- **司会の逆質問 8問**（回答者を指名して聞かれたもの．いちばん答えにくい）→ 第1節
- **発表者への質問と書式の指摘 24問**（質問の時間に出たもの）→ 第2節

質問が増えたら，回のメモの「来た逆質問」に（質問，回答者，答えられたか，型）を書き，この節に足す．

## 1. 司会の逆質問の系統（8問）

| 型 | 来た質問 | 資料のどんな文から来るか | 備え（問いの作り方） |
|---|---|---|---|
| A 命名の理由 | 「振幅特性が 0.707 となる周波数を半電力点と呼ぶ理由」 | 「〜と呼ぶ」「〜と定義する」．名前と中身が食い違って見える語（0.707 なのに「半分」） | 名前の根拠を式で言う（$0.707^2=0.5$ が電力の半分） |
| B 前提の理由 | 「入力を加える時点でシステムにエネルギーを蓄えていないものとする理由」 | 「〜ものとする」「〜と仮定する」 | 前提ごとに「なぜ置くか」「置かないと何が変わるか」．初期状態が残っていると，その分の応答が出力に混ざり，出力が入力とインパルス応答だけでは決まらなくなる |
| C 現象の理由 | 「RC フィルタの振幅特性が滑らかに変化する理由」 | 図や曲線の形を述べた文 | **素子の理由**（コンデンサの電圧は急に変われない）と**式の理由**（$\lvert H\rvert$ が連続でなめらか．理想フィルタは 1 から 0 へ飛ぶ）の2本立て |
| D 重要性の理由（簡潔に） | 「通信システムの解析において，一次モーメントおよび二次モーメントが重要な理由を簡潔に」 | 「重要」「最も」「基本」「賢明」などの評価語 | 一言版（30〜40字）と例1つ．一次は平均（直流），二次は平均2乗（電力，分散，自己相関）で，ガウス雑音は一次と二次で統計が決まる |
| E 違い | 「白色雑音とガウス雑音の違い」 | 似た語が別々の節に出る | 紛らわしい語の対を表にする．**何について言う語か**で切る（白色はスペクトルが平坦，ガウスは振幅の分布）．両方を満たす例（白色ガウス雑音）と，片方だけの例（白色だがガウスでない雑音）を言う |
| F 数を指定した列挙 | 「広義定常は，通信システム上ではどのような二つの性質によって成り立つのか」 | 定義や条件が複数ある文 | 定義・定理ごとに「条件の数と名前」を一覧にする．広義定常は，平均が時間によらず一定，自己相関が時刻の差だけの関数，の二つ．「二つあります．第一に…」と言う |
| G 大小で変わるもの | 「自己相関の幅が太いのと狭いのとで，どのようになるのか」 | 図や式のパラメータ（幅，時定数，帯域） | パラメータを大小に振った対比で答える．幅が太い（相関が長く続く）なら変化がゆっくりで帯域が狭く，狭いなら変化が速く帯域が広い（時間と周波数は逆の関係） |
| H 名詞句だけ | 「理想フィルタの位相特性」 | 見出しや語そのもの（「〜について説明して」の省略） | 見出し語ごとに「定義 → 式 → 意味」の30秒版．位相が周波数に比例し（$-2\pi ft_0$），遅れだけで波形が歪まない，など |

表：司会の逆質問8問の系統．どの型も1問ずつで，偏りはなかった．

- **式番号を指す質問は8問中0問**．「〜について式(N) を使って説明してください」の形は，この8問には1つもなかった．用語，前提，名前，重要性，違い，性質が中心で，計算問題もなかった．
- **回答者が指名される**（8問中7問に回答者名の記録があった）．誰に当たるかわからないので，自分の担当外の基礎（確率過程，ほかの人のフィルタ，前の章）も答えられるようにしておく．備えは逆質問ファイルの P（前提知識）を厚くする．
- **答えの長さや数が指定される**（「簡潔に」「二つの性質」）．先に一言版（1文）を言い，聞かれたら続ける．数を聞かれたら，最初に「二つあります」と数を言う．
- **来る文は，資料が言い切りで書いている所**．名前，前提，評価語，図の形，定義の条件は，理由が資料に書かれていないので，聞かれると答えにくい（[checklist.md](checklist.md) の観点5と同じ）．
- 答えは，資料の別のページの記述と，一般に知られた知識（回路，確率）をつないで組み立てる．資料にない推測なら，そう書く．

### 型ごとの問いのひな形

| 型 | 問い | 答えの骨格 |
|---|---|---|
| A | 「{語}を『{名前}』と呼ぶのは，なぜですか」 | 結論1文 → 名前の根拠の式1行（例：半電力点は $\lvert H\rvert=1/\sqrt2$ で，電力 $\lvert H\rvert^2=1/2$） |
| B | 「{前提}とするのは，なぜですか」「{前提}を置かないと，何が変わりますか」 | 置く理由 → 置かないと何が混ざるか → 現実で成り立つか |
| C | 「{図の形}になるのは，なぜですか」 | 素子の理由 → 式の理由 |
| D | 「{語}が重要なのは，なぜですか．一言で言ってください」 | 一言版（30〜40字）→ 例1つ → 聞かれたら続き |
| E | 「{語1}と{語2}の違いは，何ですか」 | 切る軸を1つ言う → 両方を満たす例 → 片方だけの例 |
| F | 「{定義}は，どのような{N}つの条件で決まりますか」 | 「{N}つあります．第一に…，第二に…」 |
| G | 「{パラメータ}が大きいときと小さいときで，{何}はどう違いますか」 | 大きいとき → 小さいとき → 理由（逆の関係など） |
| H | 「{見出し語}について説明してください」 | 定義 → 式 → 意味の一言 |

表：型ごとの問いのひな形．

## 2. 発表者への質問と書式の指摘の系統（24問）

自分と，ほかの3人の発表の回に出た24問（内容の質問21問と，書式の指摘3件）．

| 系統 | 問数 | 来た質問の形 |
|---|---|---|
| 図について | 9問（約4割） | 図の各部の原因（「(b) は理想的でないからこの図か」），**理想的な場合はどうなるか**，パラメータの**大小を変えたら図がどう変わるか**，**図と式の対応**（式の項が図のどこか，図に出ている量が式にない），2つの図の違い，図の言葉と本文の概念の区別 |
| 資料の一文を指す | 9問（約4割） | 「〜というのはどういうこと」，**前提の具体像と必要性**，**強調・最上級の理由**（「重要な最初の選択」「最も単純で一般的」），**〜と呼ぶ理由**，**A でなく B**（正弦波でなくパルス），現象の理由 |
| ブロック図の要素 | 3問（約1割） | 何のためか（復号で LPF を通す），**どこで行われるか**，詳しく（sample-and-hold） |
| 書式（添削） | 3件 | 式の後の段落分け，図の参照，キャプションの句点 |

表：発表者への質問24問の系統．

- 発表者が「わからない」と書いた3問は，どれも**資料に理由が書かれていない一般論**（選択が重要，最も一般的，正弦波でなくパルス）だった．
- 第1節の型A〜D と同じく，**評価語**と**前提**に「なぜ」を立てるのがいちばん当たる．

## 3. 想定質問への落とし込み

1. `check_coverage.py 資料.pdf ノート.md --sentences` の〔命名〕〔仮定〕〔評価語〕〔列挙〕の印の文に，第1節の型A，B，D，F の問いを1問ずつ立てる（〔理由なし〕〔手順〕と同じ作業表）．
2. 図ごとに，型C（形の理由）と型G（大小で変わるか），「理想ならどうなるか」，「式で書くと」を立てる．ブロック図ごとに「どこで行われるか」を立てる．
3. 似た語（白色とガウス，直交と無相関，振幅特性と位相特性）が資料にあれば，型E の違いの表を作り，逆質問ファイルの P（前提知識）に入れる．
4. 見出しの語ごとに，型H の30秒版（定義 → 式 → 意味）を作る．
5. 最優先の表には，各型から少なくとも1問を入れる．答えは先に一言版を書き，時間を指定されても言い切れるようにする．
6. 実際に来た質問は，その回の逆質問ファイルに分類 R として足し，同じ型の問いをほかの文にも立てる（[peer-notes.md](peer-notes.md)）．

実例：[examples/Kadai20261013_source.txt](../examples/Kadai20261013_source.txt) の課題1.2（「半電力点と呼ぶ理由」）は，型A の答えの作り方の実例である．
