# 元データの書式（build_qa.py の入力）

1つのテキストファイル（UTF-8）に，自由記述のブロックと，分類ごとの質問・答えを書く．
実例は `../examples/Kadai20261013_source.txt`（作者の課題原稿の268問．作者のノートの節をそのまま再現できる）．

## 全体の並び

```text
%levels 5
%head
（節の冒頭に置く説明文と「使い方」．Markdown をそのまま書く）

%practice
（索引表の後に置く「練習の順番」など．省略可）

# Z|課題全体（構成・範囲・式番号）
@3|★!||4つの課題の答えを，それぞれ一言で言ってください．
1.1は〜からです．1.2は〜からです．
@1|-|key=eqnum|式(1.81)〜(1.88)は教科書の式ですか．
教科書にない，課題で新しく立てた式です．

# A|課題1.1　RC フィルタの振幅特性が滑らかに変化する理由|課題1.1
@1|★||振幅特性とは何ですか．
…
@4|-||遮断周波数の10倍の周波数で，振幅特性はいくらですか．
…
@5|-||…

%tail
### M. 答えに詰まったときの返し方

- **どこの質問かわからない**：…
```

## 各行の意味

| 行 | 書式 | 意味 |
|---|---|---|
| 難易度の段階数 | `%levels 5` | 最初の分類より前に1回だけ書く．5段階（レベル1 超基礎〜5 発展）にする．書かなければ 1.2.0 までと同じ3段階（1 基礎，2 標準，3 発展）．値は3か5 |
| ブロックの開始 | `%head` `%practice` `%tail` | 次のブロックか分類が始まるまでの行を，そのままノートに書く |
| 分類 | `# 接頭辞\|題名` または `# 接頭辞\|題名\|短い名前` | 接頭辞は大文字の英字（Z，A，P など）．短い名前は `{{categories}}` の一覧で使う（省略すると題名） |
| 質問 | `@レベル\|フラグ\|key=参照キー\|質問文` | レベルは1〜3（`%levels 5` なら1〜5．各レベルの意味は SKILL.md の「難易度の5段階」）．フラグは `★`（聞かれやすい），`!`（最優先の表に載せる），なしは `-`．参照キーは不要なら空にする（`@1\|-\|\|質問`） |
| 答え | 質問の次の行から | 空でない行をそのまま答えにする．空行は無視される．`- **式で説明すると**：` の箇条書きや `$$…$$` の行も書ける |

## 自動で行われること

- 分類ごとに通し番号（Z1，Z2，…）を振る．質問を並べ替えると番号も変わる．
- 答えや質問文の `@@参照キー@@` を，その質問の番号に置き換える（例：`想定質問 @@theta@@ を参照` → `想定質問 B6 を参照`）．番号が変わっても参照が壊れない．
- 自由記述のブロックの次の文字列を置き換える．
  - `{{total}}`：全問数
  - `{{stars}}`：★の問数
  - `{{date}}`：更新日（`--date` で指定，既定は今日）
  - `{{categories}}`：`Z 課題全体（…），A 課題1.1，…` の形の分類の一覧
- 最優先の表（`!` の付いた質問）と難易度別の索引の表を作る．索引の列は段階数（3か5）だけ並ぶ．表のセルでは数式内の `|` を `\vert` に置き換える．
- 標準エラーに，分類ごとの問数とレベルごとの問数を出す．
- 節の並びは「`%head` → 最優先の表 → 難易度別の索引 → `%practice` → 分類ごとの全問 → `%tail`」．

## 止まる（エラーになる）もの

- 質問の答えがない，レベルが段階数の外（`%levels` なしで4以上など），参照キーの重複，未定義の参照キー
- `%levels` の値が3か5でない，`%levels` が最初の分類より後にある
- 1つの質問（質問文＋答え）の中でドル記号の数が奇数（数式の閉じ忘れ．`\$` は数えない）
- `@数字` で始まるのに区切りの `|` の数が合わない行
- 分類の接頭辞の重複，質問のない分類，分類より前にある質問
- ノートに `## 想定質問` の見出しがちょうど1つない

## 警告だけ出るもの

- `` `` `` や `''`（TeX の引用符）：Markdown（Obsidian など）ではコード扱いになるので「」に直す
- 最優先の質問が10〜25問の外
- 5段階のとき，全問の1割に届かないレベルがある

## ノートのどこを差し替えるか

`## 想定質問` の行から，次の見出し2（`## `）の手前までを差し替える．
次の見出しの直前に区切り線 `---` があれば，それは残す．
節より前と，次の見出しより後は変えない．
