# 実際に来た質問の系統

輪講で実際に出た質問を集めて，どんな型が来るかを分けたものである．想定質問を作るとき，資料の文ごとの観点（[checklist.md](checklist.md)）に加えて，この型を当てる．人名と回答者名は載せない．

- **司会の逆質問 22問**（回答者を指名して聞かれたもの．いちばん答えにくい．章全体の復習で出た4問を含む）→ 第1節
- **発表者への質問と書式の指摘 44問**（質問の時間と添削で出たもの）→ 第2節
- **先生と先輩のコメント**（学ぶ姿勢，資料の書き方，発表態度）→ 第3節

質問が増えたら，回のメモの「来た逆質問」に（質問，回答者，答えられたか，型）を書き，この節に足す．

## 1. 司会の逆質問の系統（22問）

| 型 | 来た質問 | 資料のどんな文から来るか | 備え（問いの作り方） |
|---|---|---|---|
| A 命名の理由 | 「振幅特性が 0.707 となる周波数を半電力点と呼ぶ理由」 | 「〜と呼ぶ」「〜と定義する」．名前と中身が食い違って見える語（0.707 なのに「半分」） | 名前の根拠を式で言う（$0.707^2=0.5$ が電力の半分） |
| B 前提の理由 | 「入力を加える時点でシステムにエネルギーを蓄えていないものとする理由」 | 「〜ものとする」「〜と仮定する」 | 前提ごとに「なぜ置くか」「置かないと何が変わるか」．初期状態が残っていると，その分の応答が出力に混ざり，出力が入力とインパルス応答だけでは決まらなくなる |
| C 現象の理由 | 「RC フィルタの振幅特性が滑らかに変化する理由」 | 図や曲線の形を述べた文 | **素子の理由**（コンデンサの電圧は急に変われない）と**式の理由**（$\lvert H\rvert$ が連続でなめらか．理想フィルタは 1 から 0 へ飛ぶ）の2本立て |
| D 重要性の理由（簡潔に） | 「通信システムの解析において，一次モーメントおよび二次モーメントが重要な理由を簡潔に」 | 「重要」「最も」「基本」「賢明」などの評価語 | 一言版（30〜40字）と例1つ．一次は平均（直流），二次は平均2乗（電力，分散，自己相関）で，ガウス雑音は一次と二次で統計が決まる |
| E 違い | 「白色雑音とガウス雑音の違い」「$E_b$ と $E_d$ の違い」 | 似た語，関連する物理量・記号 | 紛らわしい語の対を表にする．**何について言う語（量）か**で切る（白色はスペクトル平坦，ガウスは振幅分布／$E_b$ は1ビットの平均エネルギー（送信リソース），$E_d$ は信号間の差のエネルギー（誤り率を決める距離））．両者の関係式（対極なら $E_d=4E_b$，直交なら $E_d=2E_b$）を言う |

| G 大小で変わるもの | 「自己相関の幅が太いのと狭いのとで，どのようになるのか」 | 図や式のパラメータ（幅，時定数，帯域） | パラメータを大小に振った対比で答える．幅が太い（相関が長く続く）なら変化がゆっくりで帯域が狭く，狭いなら変化が速く帯域が広い（時間と周波数は逆の関係） |
| H 名詞句だけ | 「理想フィルタの位相特性」 | 見出しや語そのもの（「〜について説明して」の省略） | 見出し語ごとに「定義 → 式 → 意味」の30秒版．位相が周波数に比例し（$-2\pi ft_0$），遅れだけで波形が歪まない，など |
| I 式の形の理由（式指定） | 「単極信号のビット誤り率式(3.73)がこのような式になる理由」「式(3.60)で分母が $\sigma_0^2$ になる理由」 | 番号付き数式，特定の信号形式の誤り率式，比の形の式（SNR など） | 式の丸暗記ではなく，**前提となる信号配置と距離**（$s_1=A, s_2=0$ より平均エネルギー $E_b=A^2T/2$，信号間距離 $d=A\sqrt{T}=\sqrt{2E_b}$）から，なぜその係数や引数（$\sqrt{E_b/N_0}$ 等）になるのかの幾何学的・物理的理由を言う．**比の式は，分子と分母がそれぞれ何の量か**（分母の $\sigma_0^2$ は出力の雑音成分の分散＝雑音の平均電力，など）と，なぜその量で割るのかを言う．その場で導出して見せられるようにしておく |
| J 図の演算・処理の理由 | 「図3.12(b)で最初の部分で $s_1(t)-s_2(t)$ の差をとっている理由」 | ブロック図の演算素子（加算器・減算器） | 判定統計量の内積の線形性 $(r, s_1) - (r, s_2) = (r, s_1 - s_2)$ により，2系統の相関器・整合フィルタを置く代わりに，あらかじめ基準信号の差をとることで受信回路を1系統に削減できる理由を式と結びつけて言う |
| K 図の構成数の理由 | 「図3.13で相関器が二つある理由」 | ブロック図の並列素子・多系統の構成 | 「なぜ1つではダメなのか」「なぜこの個数なのか」を，信号空間の次元数（直交基底の数）やシンボル候補数 $M$（各直交成分を独立に測定する必要がある等）と結びつけて言う |
| L 方式の優劣と，劣る方を使う理由 | 「対極信号の方が直交信号よりビット誤り確率が小さくなる理由」「双極信号より誤り率の性能が劣る単極信号を使う理由」 | 複数の方式・信号形式を並べて比べる節，誤り率の曲線の比較，「〜の方が優れる」の文 | **優劣の理由**は，同じ $E_b$ のときの信号間距離 $d$ で言う（対極 $d=2\sqrt{E_b}$，直交 $d=\sqrt{2E_b}$ なので Q 関数の引数が $\sqrt2$ 倍，約 3 dB の差）．**劣る方を使う理由**は，誤り率以外の軸で言う（送受信機の簡単さ，負の振幅を出さなくてよい，光の強度変調のように負の値を出せない媒体，消費電力，同期のとりやすさ）．「性能では劣るが，〜の点で有利なので使う」の形にする |
| M 式・図を指定した説明 | 「ISI を防ぐために何を行っているのかを，図3.16を用いて説明して」「図3.24のアイパターンで ISI を，どの変数を使ってどう評価できるか」「図3.26を用いてトランスバーサルフィルタの特徴と処理の流れを説明して」．章全体の復習で「図3.2を使って尤度とは何か」「式3.30や図3.6を用いて，SN比ではなく $E_b/N_0$ を使う理由」「式3.72と式3.74を用いて単極信号と双極信号について説明して」 | 節の中心の図（仕組みを描いた図，アイパターン，ブロック図）と，対になる2本の式 | **図・式を指定されたら，必ずその図・式を指して答える**．図は「どこに何が描いてあるか → 何を示すか → 聞かれたことの答え → 式との対応」の順に，指す場所の順番まで決めておく（図3.16 なら，(a) の矩形の帯域 → (b) の sinc の主ローブ → 隣のパルスの頂点で裾が0を通る黒い点）．図の中の**変数や記号を聞かれる**ので，図の記号ごとに何を測るかの一覧を作る（アイパターンなら，目の縦の開きが雑音余裕 $M_N$ のように，ISI による歪み，タイミングのゆらぎ，タイミング誤差への感度がそれぞれどの記号か）．2本の式を指定されたら，違う所（項，係数，引数）を対比して言う．処理の流れは，入力から出力へ素子を順にたどる |

- **式番号を指す質問（「式(N) を使って説明してください」「式(N) がこうなる理由は？」）は頻出する**．単に数式の変形をなぞるのではなく，「なぜその係数・引数になるのか（信号間距離 $d$ やエネルギー $E_b$ との対応）」「分子と分母がそれぞれ何の量か」を幾何学的・物理的に説明できるようにしておく．
- **図に関して式を使わせる質問，ブロック図の構成理由が突かれる**．「図のこの演算は何のためか（型J）」「なぜこの素子がN個あるのか（型K）」は，対応する数式（判定統計量の式，信号空間の次元）と必ずセットで答える．
- **複数ある図や方式の違いを様々な観点から聞かれる**．(a)と(b)の図，あるいは異なる方式のブロック図がある場合，観点（等価性，実装の簡略化，時間波形 vs 周波数スペクトル，理想 vs 実現可能）を明示して比較する．方式どうしは，優劣の理由と，劣る方を使う理由の両方を用意する（型L）．
- **式・図を指定して説明させる質問（型M）がいちばん多くなった**．「図N を用いて説明して」「式N と式M を用いて説明して」の形で，22問中6問．指定された図・式を使わずに言葉だけで答えると，聞かれたことに答えたことにならない．
- **回答者が指名される**．誰に当たるかわからないので，自分の担当外の基礎（確率過程，ほかの人のフィルタ，前の章）も答えられるようにしておく．備えは逆質問ファイルの P（前提知識）を厚くする．
- **章の終わりに全体の復習がある**．担当範囲ごとに1問ずつ，その範囲の中心の図・式を指定して聞かれる（尤度と図3.2，$E_b/N_0$ と式3.30・図3.6，単極と双極と式3.72・式3.74．図の指定がないものも「ナイキストフィルタでどう ISI をなくすか」）．ほかの人の範囲は，**中心の図1枚と式1〜2本で30秒説明**を用意しておく（逆質問ファイルの U，P）．
- **答えの長さや数が指定される**（「簡潔に」「二つの性質」）．先に一言版（1文）を言い，聞かれたら続ける．数を聞かれたら，最初に「二つあります」と数を言う．
- **来る文は，資料が言い切りで書いている所**．名前，前提，評価語，図の形，定義の条件，数式の導出省略は，理由が資料に書かれていないので，聞かれると答えにくい（[checklist.md](checklist.md) の観点5と同じ）．
- 答えは，資料の別のページの記述と，一般に知られた知識（幾何学的距離，回路，確率）をつないで組み立てる．資料にない推測なら，そう書く．

| E | 「{語1}と{語2}の違いは，何ですか」 | 切る軸を1つ言う（送信リソース vs 幾何学距離など） → 両者の関係式（$E_d$ と $E_b$ など） |
| F | 「{定義}は，どのような{N}つの条件で決まりますか」 | 「{N}つあります．第一に…，第二に…」 |
| G | 「{パラメータ}が大きいときと小さいときで，{何}はどう違いますか」 | 大きいとき → 小さいとき → 理由（逆の関係など） |

| I | 「式({N.NN}) がこのような式になるのは，なぜですか」「式({N.NN}) で分母が{量}になるのは，なぜですか」 | 結論（信号配置と距離，または分子・分母の量） → 距離 $d$ と $E_b$ の関係（分母・分子なら，その量で割る意味） → 引数の係数の根拠 |
| J | 「図{N.NN} で {演算・処理} を行っているのは，なぜですか」 | 結論（回路の簡略化等） → 対応する判定統計量の式 → 2系統を1系統にまとめられる理由 |
| K | 「図{N.NN} で {素子} が {N} 個あるのは，なぜですか」 | 結論（次元数またはシンボル数） → 1つでは足りない理由 → 各成分の直交性・独立性 |
| L | 「{方式1}の方が{方式2}より{性能}がよいのは，なぜですか」「{性能}で劣る{方式2}を使うのは，なぜですか」 | 優劣：同じ $E_b$ での距離 $d$ → Q 関数の引数 → dB の差．劣る方：「性能では劣るが」→ 有利な軸（実装，媒体の制約，電力）→ 使われる場面 |

- 発表者が「わからない」と書いた3問は，どれも**資料に理由が書かれていない一般論**（選択が重要，最も一般的，正弦波でなくパルス）だった．
- 第1節の型A〜D，I〜L と同じく，**評価語**，**前提**，**数式の形の根拠**，**図のブロックの演算理由**，**方式の優劣**に「なぜ」を立てるのがいちばん当たる．
- 図のパラメータの質問は，**トレードオフの理由**まで聞かれる（帯域を広げると裾が小さくなるのはなぜか）．答えは「周波数を急に切ると，時間に長く裾を引く（縁がなだらかなほど裾が速く減衰する）」のように，時間と周波数の対応で言う．
- 最上級（「最もよく用いる」）の理由は，**資料の別のページの性質を集めて2〜3個**で答える（裾が小さく ISI が混入しにくい，近似して実装しやすい，送受に分けると整合フィルタになる，など）．
- 前の章の概念との違いは，**どの領域で起きるか**で切る（ISI は時間領域でパルスの裾が重なる，エイリアシングは周波数領域で標本化による複製が重なる）．
- **手順・アルゴリズム・式には「前提が崩れたら」「端の場合は」が来る**．資料が「〜と仮定する」「〜が正しいとする」と書く所（過去の判定が正しい，雑音を考えない）には「外れたら何が起きるか」（誤りが後へ伝わる，雑音を強調する）を，逐次の処理には「最初の1回はどうするか」（トレーニング系列で始める，など）を，分数の式には「分母が0になったら」を，場合分けの式には「境界の値はどちらに入るか」を立てる．
- **資料が一方を「主に使う」と書いたら，もう一方の使い道が聞かれる**．利点（計算が簡単，など）と，向いている場面を一つずつ用意する．
- 原著の式の書き落とし（場合分けの等号がない）は，「原著に書かれていない」と事実を言ったうえで，どちらに入れても値が変わらない（連続している）ことを添えると答えが締まる．

## 3. 先生と先輩のコメント（学ぶ姿勢，資料，発表態度）

質問の形ではないが，輪講の場で言われたこと．想定質問と原稿の作り方に効くものだけを載せる．

| 何について | 言われたこと | 想定質問・原稿への反映 |
|---|---|---|
| 数式 | 数式はすぐに導出できないといけない | 番号付きの式ごとに「その場で導出してください」の問いを立て，導出を3〜5段に分けた答えを書く（型I） |
| 疑う姿勢 | 違う事実が出てきたら疑う．常に疑う．もっと疑っていこう | 資料の中で食い違って見える所（図と式の値の違い，前の節と今の節の言い方の違い）に「なぜ違うのか」の問いを立てる．質問する側に回るときも，ここを聞く |
| 知識のつなぎ方 | 体系的に整理する．説明するために知識をつなぐのが勉強．受け身だと伸びない | 前の章・ほかの人の範囲とのつながりの問い（逆質問の P，U）を厚くし，答えに「どの節の何とつながるか」を一言添える |
| 説明の練習 | 受け答えの練習，過不足のない説明の練習は今しかできない | 答えは一言版 → 理由 → 式の順にし，聞かれていない補足を足さない（rinkou-qa の own-talk.md の「話し方の決まり」） |
| 資料の中身 | 教科書にない「最後に」の段落に「何が言いたいの」と聞かれた | 資料や課題に教科書にない内容を書いたら，その目的を一文で言う問いを立てる．目的が言えないなら書かない |
| 図の説明 | 図を図面として説明できるようにする | 図ごとに「この図を使って説明してください」の問いを立て，答えは「どこに何が描いてあるか → 何を示すか → 式との対応」の順にする |
| 発表態度 | 手元や画面ばかり見ていた | 原稿の「発表時の注意」に，聞き手を見ることを書く（rinkou-qa の own-talk.md） |

## 4. 想定質問への落とし込み

1. `check_coverage.py 資料.pdf ノート.md --sentences` の〔命名〕〔仮定〕〔評価語〕〔列挙〕の印の文に，第1節の型A，B，D，F の問いを1問ずつ立てる（〔理由なし〕〔手順〕と同じ作業表）．
2. 番号付き数式，特に性能評価式（誤り率など）には，型I（式の形の理由・幾何学距離とエネルギーとの関係，比の式なら分子と分母の量）を立てる．その場で導出させる問いも立てる（第3節）．
3. 図ごとに，型C（形の理由）と型G（大小で変わるか，トレードオフの理由），型J（演算・差分の理由），型K（構成数・素子の個数の理由），型M（「この図を用いて〜を説明して」．指す順番と，図の記号ごとの意味も），「理想ならどうなるか」，「式で書くと」を立てる．複数図があれば観点を変えた比較（型E）を立てる．ブロック図ごとに「どこで行われるか」を立てる．
4. 似た語や関連する物理量・記号（$E_b$ と $E_d$，白色とガウス，直交と無相関，振幅特性と位相特性，ISI とエイリアシング）が資料や前の章にあれば，型E の違いの表を作り，逆質問ファイルの P（前提知識）に入れる．
5. 複数の方式・信号形式（単極・対極・直交など）が並ぶ節では，型L（優劣の理由と，劣る方を使う理由）を立てる．
6. 「〜と仮定する」「〜が正しいとする」の文，逐次の処理，分数の式，場合分けの式には，「前提が崩れたら」「最初の1回は」「分母が0なら」「境界は」の問いを立てる（第2節）．資料が「主に使う」と書いた方式には，もう一方の使い道の問いを立てる．
7. 見出しの語ごとに，型H の30秒版（定義 → 式 → 意味）を作る．
8. 章の最後の回の前に，ほかの人の範囲ごとに「中心の図1枚と式1〜2本で30秒説明」を作る（型M．全体の復習で聞かれる）．
9. 最優先の表には，各型から少なくとも1問を入れる．答えは先に一言版を書き，時間を指定されても言い切れるようにする．
10. 実際に来た質問は，その回の逆質問ファイルに分類 R として足し，同じ型の問いをほかの文にも立てる（[peer-questions.md](peer-questions.md)）．

実例：[examples/Kadai20261013_source.txt](../examples/Kadai20261013_source.txt) の課題1.2（「半電力点と呼ぶ理由」）は，型A の答えの作り方の実例である．
